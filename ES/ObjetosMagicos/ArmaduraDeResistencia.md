# Armadura de resistencia

*Armadura (ligera, media o pesada), rara (requiere sintonización)*

Tienes resistencia a un tipo de daño mientras lleves esta armadura. Tu GM elige el tipo o lo determina al azar tirando en la tabla a continuación.

| 1d10 | Tipo de daño |
|---|---|
| 1 | Ácido |
| 2 | Frío |
| 3 | Fuego |
| 4 | Fuerza |
| 5 | Necrótico |
| 6 | Psíquico |
| 7 | Radiante |
| 8 | Relámpago |
| 9 | Trueno |
| 10 | Veneno |
