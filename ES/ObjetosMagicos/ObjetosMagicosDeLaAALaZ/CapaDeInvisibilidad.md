# Capa de invisibilidad

*Objeto maravilloso, legendario (requiere sintonización)*

Esta capa tiene 3 cargas y recupera 1d3 cargas empleadas cada día, al amanecer. Mientras la lleves puesta, puedes emplear una acción de magia para ponerte la capucha y gastar 1 carga para otorgarte el estado de invisible durante 1 hora. El efecto termina antes de tiempo si te quitas la capucha (no requiere acción) o dejas de llevar puesta la capa.
