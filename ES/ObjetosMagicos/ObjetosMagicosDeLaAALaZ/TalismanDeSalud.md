# Talismán de salud

*Objeto maravilloso, infrecuente (requiere sintonización)*

Mientras lleves este colgante, puedes emplear una acción de magia para recuperar 2d4 + 2 puntos de golpe. Una vez utilizada, esta propiedad no puede volver a usarse hasta el siguiente amanecer.

Además, tienes ventaja en las tiradas de salvación para evitar o poner fin al estado de envenenado mientras lleves puesto el colgante.
